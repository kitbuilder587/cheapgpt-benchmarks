# Third-party benchmarks

This repository does not vendor benchmark datasets or harness source code. `benchmarks.lock.yaml`
identifies the upstream repositories and commits fetched for a run. Each benchmark remains under
its own license and access terms; users are responsible for satisfying dataset-specific terms,
including GPQA access requirements.

Adapters must preserve upstream attribution and must not redistribute restricted prompts through
the Python wheel. Public run artifacts are reviewed against the applicable benchmark license before
release.
